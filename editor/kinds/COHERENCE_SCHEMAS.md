# Coherence Pass - file schemas

Companion to [registry.py](registry.py) per-id overrides for `cp_fixture`, `cp_chrome`, `lint_*`, `v_*`, `cp_coherence_gate`. The Coherence Pass writes three artifact files and one decision file. Schemas below.

Cross-references: [`COHERENCE_PHASE_PLAN.md`](../../projects/super/COHERENCE_PHASE_PLAN.md) (per-project plan that motivated this), [`coherence-auditor.md`](../../.claude/agents/coherence-auditor.md) (Subagent 11 playbook).

---

## 1. `source/<branch>/_coherence/model.json` - canonical entity store

Owner: `cp_fixture` (agent-kind, per-id override). One source of truth for every numeric / proper-noun fact in the generated prototype.

```json
{
  "version": "1",
  "generatedAt": "2026-05-27T17:50:00Z",
  "entities": {
    "case:SNT-2614-PORT": {
      "title": "Coordinated port-closure campaign",
      "amplifiers": 312,
      "windowMin": 49,
      "confidence": 0.92,
      "grade": "High",
      "origin": "@harbour_voice",
      "carries": "synthetic-minister-clip"
    },
    "case:SNT-2614-WHARF": { ... },
    "operator:duty-officer-A": { ... }
  },
  "stateTransitions": {
    "case:SNT-2614-PORT": [
      { "at": "T-2h",   "state": "trending",    "confidence": 0.74 },
      { "at": "T-0",    "state": "escalate",    "confidence": 0.92 },
      { "at": "T+30m",  "state": "dispatched",  "operator": "operator:duty-officer-A" }
    ]
  }
}
```

**Rules for downstream consumers (`bs_html_*` generators):**

- Every numeric/named fact in page prose MUST come from `window.DEMO` (which derives from `model.json`), never re-typed inline.
- If a fact isn't in `model.json`, the generator MUST request it via the orchestrator, not invent it.

## 2. `source/<branch>/data.js` - per-surface views

Owner: `cp_fixture` (same node, second file). The per-surface `window.DEMO` object every page reads.

```javascript
// Generated by cp_fixture. DO NOT hand-edit values - they reference model.json.
window.DEMO = {
  standingBrief: {
    primary: window.MODEL.entities["case:SNT-2614-PORT"],
    trending: [
      { ref: "case:SNT-2614-WHARF", confidence: window.MODEL.entities["case:SNT-2614-WHARF"].confidence }
    ]
  },
  verdictCard: {
    case: window.MODEL.entities["case:SNT-2614-PORT"],
    evidence: { ... }
  },
  auditTrail: { ... }
};
```

The exact shape depends on the PRD's surfaces. The invariant: **no literal numbers** in `data.js`; everything is a reference into `window.MODEL` (which is `model.json` loaded as a global).

Owner: `cp_chrome` (agent-kind, per-id override). Machine-readable target for `lint_chrome_consistency`.

  "generatedAt": "2026-05-27T17:50:00Z",
  "brandSymbolId": "sentinel-mark",

## 4. `source/<branch>/COHERENCE_REPORT.json` - audit findings

Owner: shared by `lint_data_coherence`, `lint_chrome_consistency`, and every `v_<assetId>`. Each commit appends to the same file.

```json
{
  "version": "1",
  "generatedAt": "2026-05-27T17:50:00Z",
  "branch": "main",
  "findings": [
    {
      "lint":     "data" | "chrome" | "vision",
      "rule":     "R1" | "R2" | "R3" | "R4",
      "severity": "block" | "warn",
      "surface":  "verdict-card.html" | "<asset-path>",
      "entity":   "case:SNT-2614-PORT.amplifiers",
      "expected": 312,
      "found":    38,
      "notes":    "..."
    }
  ],
  "summary": {
    "total":    6,
    "blocking": 2,
    "byLint":   { "data": 3, "chrome": 2, "vision": 1 },
    "byRule":   { "R1": 4, "R2": 1, "R4": 1 }
  }
}
```

## 5. `DECISION_cp_coherence.json` - gate verdict

Owner: `cp_coherence_gate` (agent-kind, per-id override). Same shape as other `DECISION_*.json` files.

```json
{
  "id": "cp_coherence",
  "values": ["clear"],
  "value":  "clear",
  "labels": ["Coherence pass - all blocking findings cleared"],
  "answeredAt": "2026-05-27T17:55:00Z",
  "waived": []
}
```

Or, when block findings exist and the user chose Accept-override:

```json
{
  "id": "cp_coherence",
  "values": ["override"],
  "value":  "override",
  "labels": ["Manually waived 2 blocking findings"],
  "answeredAt": "2026-05-27T17:55:00Z",
  "waived": [
    { "finding": {"lint": "data", "rule": "R1", ...}, "reason": "intentional sketch divergence" }
  ]
}
```

When `value == "clear"` or `"override"`, the prototype node can flip to `done`. Anything else keeps the prototype gated.

## Reconciler integration

The reconciler ([reconcile.py](reconcile.py)) treats absence of `COHERENCE_REPORT.json` AND a finished pipeline (all `bs_html_*` and `br_remix_*` done) as a drift:

```
{ "type": "COHERENCE_NOT_RUN", "class": "manual",
  "suggest": "dispatch Subagent 11 (Coherence) via Task tool to audit; see coherence-auditor.md" }
```

A future enhancement (deferred): once Subagent 11 stabilizes, promote this to auto-class - the reconciler dispatches the audit itself when it detects all generation stages done + no coherence report.
