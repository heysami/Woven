## Logic kind catalogue (generated from the shared registry)

- `input-pointer` [space, button] - (i) none - (o) x(number) y(number) isDown(boolean) clicked(event) downX(number) downY(number) upX(number) upY(number) hover(boolean) pos(vector2). Mouse / single-pointer on the render surface
- `input-touch` [maxPoints, space] - (i) none - (o) count(number) pos(vector2) touches(vector2) isDown(boolean) center(vector2) spread(number) pinchDelta(number) rotation(number) tap(event). Multi-touch on the render surface
- `input-keyboard` [key, repeat] - (i) none - (o) key(string) isDown(boolean) pressed(event) released(event) axisX(number) axisY(number). Keyboard on the render surface
- `input-scroll` [space, clampMin, clampMax] - (i) none - (o) deltaY(number) deltaX(number) accumY(number) accumX(number) velocity(number). Wheel / scroll on the render surface
- `input-gyro` [smoothing] - (i) none - (o) alpha(number) beta(number) gamma(number) tilt(vector2) ready(boolean). Device orientation (mobile-primary)
- `input-audio` [source, band, fftSize, smoothing] - (i) asset(string) - (o) level(number) pitch(number) band(number) beat(event) spectrum(channel) bands(channel). Microphone / audio asset level, pitch, bands
- `input-gamepad` [] - (i) none - (o) leftStick(vector2) rightStick(vector2) x(number) y(number) a(boolean) b(boolean) connected(boolean). Gamepad sticks + buttons (no permission)
- `input-accel` [] - (i) none - (o) x(number) y(number) z(number) ready(boolean). Device motion / accelerometer (permission-gated)
- `input-midi` [] - (i) none - (o) note(number) velocity(number) cc(number) ccValue(number) gate(boolean) ready(boolean). WebMIDI controller: note / velocity / CC (permission-gated)
- `input-camera` [facing, resolution] - (i) none - (o) stream(string) ready(boolean) layer(layer). Live webcam stream handle
- `input-video` [loop, autoplay] - (i) asset(string) - (o) stream(string) t(number) playing(boolean) layer(layer). A video asset / clip as a stream handle
- `vision-detect` [detector, target, hand] - (i) stream(string) - (o) present(boolean) count(number) pos(vector2) region(region) gesture(string) confidence(number) wrist(vector2) thumbTip(vector2) indexTip(vector2) middleTip(vector2) ringTip(vector2) pinkyTip(vector2) nose(vector2) leftEye(vector2) rightEye(vector2). MediaPipe Tasks Vision: face / hand / object detection
- `vision-ocr` [query, interval] - (i) stream(string) - (o) text(string) matched(boolean) region(region) count(number). tesseract.js text recognition over a stream
- `palette` [count, quality] - (i) image(string) - (o) color0(color) color1(color) color2(color) color3(color) color4(color) color5(color) color6(color) color7(color) dominant(color) domR(number) domG(number) domB(number) ready(boolean) count(number). Extract N dominant colors from a wired image
- `value-bool` [value] - (i) none - (o) value(boolean). Constant boolean value
- `value-string` [value] - (i) none - (o) value(string). Constant text value
- `value-vec2` [x, y] - (i) none - (o) value(vector2). Constant {x,y} vector
- `op-math` [op] - (i) a(number) b(number) - (o) r(number). Binary math on two numbers
- `op-unary` [op] - (i) a(number) - (o) r(number). Unary math on one number
- `op-compare` [op, epsilon] - (i) a(number) b(number) - (o) r(boolean). Compare two numbers, emit boolean
- `op-logic` [op] - (i) a(boolean) b(boolean) - (o) r(boolean). Boolean logic on two booleans
- `op-map` [inMin, inMax, outMin, outMax, clamp, ease] - (i) x(number) - (o) r(number). Remap + clamp + ease a number
- `op-vector` [mode] - (i) x(number) y(number) v(vector2) a(vector2) b(vector2) t(number) - (o) v(vector2) x(number) y(number) d(number). Make / break / measure vec2
- `op-tostring` [template] - (i) a(number) - (o) s(string). Format a value into a string
- `flow-if` [] - (i) cond(boolean) then(number) else(number) - (o) r(number). Pass then-branch when cond, else else-branch
- `flow-gate` [holdLast] - (i) value(number) open(boolean) - (o) r(number). Pass value only while open; else hold last
- `flow-while` [maxIterations] - (i) cond(boolean) body(number) - (o) count(number) last(number). Samples the memoized body up to maxIterations when condition is true; does not run a subgraph loop
- `flow-repeat` [] - (i) n(number) body(number) - (o) sum(number) values(number). Repeats a memoized value; index affects external number sources only
- `state-counter` [step, wrap] - (i) inc(event) reset(event) - (o) count(number). Count inc events; reset clears
- `state-toggle` [initial] - (i) flip(event) - (o) on(boolean). Flip a boolean on each flip event
- `state-latch` [] - (i) set(boolean) hold(number) - (o) value(number). Sample hold when set rises, then keep it
- `state-timer` [autostart] - (i) start(event) stop(event) - (o) elapsed(number) running(boolean). Elapsed time between start / stop events
- `state-smooth` [stiffness, damping] - (i) target(number) - (o) value(number). Critically-damped pursuit of a target number
- `gen-lfo` [wave, freq, phase, lo, hi] - (i) none - (o) value(number) phase(number). Low-frequency oscillator (sine/tri/saw/square)
- `gen-noise` [speed, seed, lo, hi] - (i) none - (o) value(number). Smooth value noise over time
- `gen-clock` [] - (i) none - (o) time(number) frame(number) fps(number). Wall clock: time, frame count, fps
- `op-slope` [] - (i) x(number) - (o) slope(number). Rate of change (derivative) of a number
- `chop-filter` [mode, cutoff] - (i) x(number) - (o) value(number). One-pole low/high-pass smoothing filter
- `state-delay` [frames] - (i) x(number) - (o) value(number). Delay a number by N frames
- `state-trigger` [attack, decay, sustain, release] - (i) gate(event) - (o) value(number). ADSR envelope driven by a gate event
- `state-trail` [length] - (i) x(number) - (o) channel(channel). Record a number into a rolling channel (a scope)
- `chan-sample` [mode] - (i) channel(channel) index(number) phase(number) - (o) value(number). Read one sample of a channel by index or phase
- `chan-analyze` [mode] - (i) channel(channel) - (o) value(number). Reduce a channel to a number (min/max/avg/rms/sum)
- `dat-fetch` [url, method, pollMs] - (i) none - (o) text(string) value(number) ok(boolean) updated(event). Poll a URL (CORS) and cache the response
- `op-json-path` [path] - (i) text(string) - (o) value(number) text(string). Extract a value from a JSON string by dotted path (a.b[0].c)
- `dat-websocket` [url] - (i) none - (o) message(string) value(number) connected(boolean) updated(event). Live WebSocket: latest message + connected flag
- `control-panel` [a, b, c, d, toggle] - (i) none - (o) a(number) b(number) c(number) d(number) on(boolean). Live sliders + toggle to drive params
- `force` [type, radius, strength, falloff] - (i) pos(vector2) - (o) out(force). Generic physics force into the composer's shared world
- `shape` [closed, fill, stroke, strokeWidth, opacity, blend, z, smoothing] - (i) p0(vector2) p1(vector2) p2(vector2) p3(vector2) p4(vector2) p5(vector2) p6(vector2) p7(vector2) fill(color) stroke(color) content(asset/layer/effect) - (o) out(layer). Polygon / polyline from wired vector2 points
- `type-motion` [text, font, weight, size, color, tracking, align, behavior, speed, amplitude, stagger, path, pathRadius, pathAmplitude, pathRotate, loop, opacity, blend, z, feedback] - (i) none - (o) out(layer). Per-glyph animated text (kinetic typography)
- `audio-out` [waveform, frequency, gain, cutoff] - (i) frequency(number) gain(number) cutoff(number) trigger(event) - (o) out(audio-out). WebAudio synth: oscillator -> gain -> lowpass -> out

Vector modes: make x/y -> v; break v -> x/y; distance a/b -> d; add a/b -> v; scale v/t -> v; lerp a/b/t -> v.
op-tostring supports {v}, {a}, {x}, and {y}. See dataflow for per-node input controls, ownership, delay, and bounded sampling semantics.
