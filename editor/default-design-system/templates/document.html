Boxless editor - Product spec

This document describes the boxless editing surface: a writing canvas where forms have no visible chrome. You click the text to edit it. Nothing reads as an input until you hover or focus it — the page looks like a finished document, not a form.

Summary

We are replacing the bordered field grid on the project-brief screen with a document register. Every value — owner, status, due date — is plain text inline, editable on click. The affordance is the hover tint and the focus underline, not a box.

Principle. The form should disappear. If a teammate can read the page top-to-bottom and understand the project without noticing a single control, the chrome did its job by getting out of the way.

Goals

  • Reads as a document at rest — no borders, no fills, no labels-in-boxes.
  • Hover reveals the editable region with a faint tinted pad.
  • Focus shows a single low-key underline; the box outline never returns.
  • Slash menu for inserting blocks; drag handle for re-ordering.
