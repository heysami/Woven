woven-voice harness

Manual + automated fixture for editor/woven-voice.js. Serve the repo root statically (the repo-root-static preview config) and open /editor/tests/voice-harness.html. With no daemon behind it, every capability probe fails and the helper must fall back to browser speech rather than break. With the daemon running, the same page exercises the real /__voice/* routes. Results accumulate on window.__results for headless assertions.
