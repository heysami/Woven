**DEPRECATED.** A 3D simulation scene is no longer hand-built here. The render is the shared `scene-3d` layer (per-subsystem fan-out, each subsystem rendering standalone, drivable output). The simulation-orchestrator co-dispatches `scene-3d-orchestrator` with `mode: host-driven` and `drivenHandles` = the entities the sim loop moves; the loop then calls `window.__scene3d.step(state, alpha)` each frame. Read `scene-3d-orchestrator.md` + `s3d-subsystem-author.md`. The "3D must feel 3D" contract (look around AND move inside) is enforced by the scene-3d lens gates. Return `runStatus: error` pointing the caller at `scene-3d-orchestrator` unless finishing a legacy `simulations/<simId>/` 3D build.
