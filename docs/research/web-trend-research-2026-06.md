# Web trend research - motionsites.ai + Awwwards parallax + Awwwards SOTD (June 2026)

Research pass commissioned to grow the design library (shell / style / aesthetic / photography / illustration)
from three sources:

1. **motionsites.ai** - 97 cards (animated hero/landing showcases; poster frame per card analyzed)
2. **Awwwards "30 Great Websites with Parallax Scrolling"** - 30 entries (article screenshots, per user instruction)
3. **Awwwards Sites of the Day** - first 20 submissions (main screenshot + tags + one-line breakdown)

Evidence: labeled contact sheets + per-sample metadata live in `docs/research/web-trend-research-2026-06/`
(`motionsites-sheet-*.jpg` ×9, `parallax-sheet-*.jpg` ×3, `sotd-sheet-*.jpg` ×2, plus the scraped
`*-cards.json` / `*-entries.json` / `meta.json` with every sample's title, tags and source URL).
Raw full-size frames remain at `/tmp/libresearch/` if needed before reboot.

Classification vocabulary = our five library dimensions. Existing IDs are referenced bare
(`shell-hero-stack`, `style-aurorism`, `aesthetic-solarpunk`, photo `apple-clean-studio`, illust `voxel-magicavoxel`).
Proposed additions are marked **NEW:** and resolved in §4 (the grouping).

## 4. GROUPING - proposed new library additions

Clusters across all 147 samples, deduplicated against the existing libraries. Ordered by evidence strength
(sample count). Member lists use `ms`=motionsites, `px`=parallax, `sd`=SOTD.

### 4a. New SHELLS (2)

| Proposed | Evidence | Gap rationale |
|---|---|---|
| **shell-horizontal-scroll-stage** | px00, px14, px15, px16, px19, px27, px29 (7) | Full-bleed horizontal scroll/slideshow as the page's primary axis - chapters/panels traversed sideways, often mixed H/V. We have `infinite-canvas` (2D free) and `canvas-floating` but NO horizontal-first shell. Motion lib has the scrub mechanics; the *layout skeleton* is missing. |
| **shell-scroll-journey-scene** | ms26, px03, px21, px25, sd18 (5) | One continuous illustrated/3D scene that scroll traverses (underwater dive, product macro flight, theater dolly). Distinct from hero-stack: there are no sections, only one scene with stations. Pairs with motion `scroll-scrub-journey`. |
| *(watchlist)* shell-desktop-os-metaphor | sd03 (1) | OS desktop with draggable windows/strewn files as a portfolio. Only one sighting - hold until seen again; can be approximated by `canvas-floating`. |

### 4b. New STYLES (3)

| Proposed | Evidence | Gap rationale |
|---|---|---|
| **style-silk-chrome-flow** | ms10, ms11, ms15, ms27, ms34, ms38, ms93, ms94 (8) | THE dominant dark-SaaS hero treatment of this crop: iridescent silk / chrome ribbon / aurora membrane flowing across a near-black field, type floating above. ### 4f. Cross-dimension observations for the orchestrators

1. **The italic-serif accent word** (`style-editorial-italic-accent`) appears in ~10% of ALL samples - cheap, high-yield rule for the prototype skill + scrapbook-typography-author + visual-orchestrator type briefs.
2. **The two missing shells are both scroll-axis shells.** Every parallax-article standout is either horizontal-stage or journey-scene; our shell library is entirely vertical-section-based today. These two unlock the whole parallax genre for interactive-polish + narrative-experience.
3. **Dark-SaaS heroes have ONE new uniform: silk-chrome-flow.** When briefs say "premium AI SaaS", this - not aurorism - is the current reference register. Should become a first-class style with a shader/video implementation note for visual-orchestrator (`shader` or `motion` medium).
4. **Calm-tech is a coherent register** (pastoral-serene + lofi-contemplative + organic-overgrowth): photo/illustration libraries should cross-link these so photography-orchestrator and illustration-orchestrator can chain them per slot role.
5. **SOTD breakdowns confirm the recipe**: tags repeatedly pair an expressive aesthetic with restrained shells + one signature motion (GSAP scroll choreography). Polish-orchestrator's register table matches; the new aesthetics should declare their polish register explicitly (e.g. monochrome-pop-poster → theatrical; pastoral-serene → subtle).
