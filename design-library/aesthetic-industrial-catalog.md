# Industrial Catalog (aesthetic)

**Tag:** Machine spec-sheet brutalism (Automation Machines robot-arm pages; ZettaJoule "Powering the World"; Vitsoe/USM catalogs; KUKA/FANUC product sheets)

**Canonical references:**
- Automation Machines (motionsites) — photoreal robot arm, techno-mono headline, spec rows.
- ZettaJoule (Awwwards SOTD) — industrial machinery photography inside clean white frames, gradient display type.
- Vitsoe / USM Haller printed catalogs — furniture-as-engineering documentation.
- KUKA / FANUC / Festo industrial product sheets; Dieter Rams' Braun catalogs as ancestors.

## Cultural identity

The industrial product CATALOG as a design language: photoreal machinery (robot arms, turbines, fixtures) photographed like furniture, surrounded by engineering apparatus — payload tables, axis diagrams, part numbers, tolerance specs — set in mono and grotesque on disciplined light grounds. The machine is beautiful BECAUSE the documentation is rigorous. Distinct from `aesthetic-frutiger-dorfic` (safety-orange corporate-futurist mood) — Industrial Catalog is literal: it reads like you could ORDER the machine from this page. Sibling of `aesthetic-monochrome-tech-editorial` (which is archival b/w; this is current, color, in-production).

The defining gesture is **the spec block beside the glamour shot**: hero machine photo + a real table (REACH 1300mm / PAYLOAD 12kg / REPEAT ±0.02mm) given equal typographic care.

**Palette anchor:** workshop white `#f4f4f2` / light gray `#e6e7e5`, machine grays + one industrial accent (safety orange `#f25c1f`, signal yellow `#ffd02f`, or machine green `#1f6e4f`), ink `#1c1d1e`, mono labels `#6f7276`.

## Motifs / imagery vocabulary

- Photoreal machine hero on seamless light ground or in-situ workshop shot (photo register: clean industrial studio).
- Spec apparatus: dimension tables, axis-range diagrams, exploded-view callouts, part numbers (`AM-340-B`), QA stamps.
- Techno-grotesque or mono display for machine names ("AUTOMATION MACHINES"); letterspaced caps.
- Hairline-ruled grids; numbered sections (01 / 02 / 03) like manual chapters.
- Motion: the machine MOVES once — an arm cycle, a rotation demo — then rests; spec values may count up on entry.

**Raster required:** the machinery photography/render (photo `apple-clean-studio` industrial mode or commissioned renders; illust `3d-technical-exploded-precision` for exploded views).

## Voice register

Datasheet declarative: capabilities as measurements, never adjectives ("Repeatability ±0.02 mm" beats "incredibly precise"). German-engineering terseness. Warranty-grade promises only.

## Failure mode

Dark cyber-grid + glowing HUD = wrong register (that's blueprint-hologram); machine photo with no specs = generic product page; distressed textures or grunge type (the catalog is PRISTINE — precision is the aesthetic). The tell: a real, plausible spec table.

## Best for

Robotics/automation companies, industrial hardware and energy, machine-tool and component makers, premium furniture systems, logistics equipment, B2B manufacturing platforms.
