# Spline-era browser-3D bubbly product

The Spline / Vercel / Stripe / Linear-era browser-3D hero aesthetic — soft volumetric blobs, glossy plastic spheres, iridescent holographic gradients, interactive 3D shapes that float, morph, and respond to scroll/pointer. The 2022-2026 dev-tools / AI-product / fintech landing-page register.

## Visual signatures

- soft volumetric blobs and glossy plastic primitives (spheres, toruses, soft cubes)
- subdivision-surface organic forms (subdivide-and-smooth on a base mesh)
- Lambert + soft shadow shading with subtle subsurface scatter
- iridescent holographic gradients sweeping the surface (often OKLCH conic)
- saturated-pastel palette — lavender, mint, peach, sky, coral, jade
- floating composition, no ground plane, soft drop-shadow only
- often interactive — rotates, morphs, follows cursor (Spline canvas signature)
- crisp web-render quality (anti-aliased, accurate AO at corners)

## Prompt keywords

**Primary**: Spline 3D, soft volumetric blob, glossy plastic sphere, iridescent holographic gradient, floating hero shape

**Material**: glossy plastic, soft subsurface, iridescent OKLCH gradient sweep, sharp specular highlight

**Line**: no line, edge-shaded only

**Color**: saturated-pastel — lavender + mint + peach + sky + coral (often two-tone iridescent)

**Style**: floating composition, soft drop-shadow, no ground plane, web-render quality

**Avoid (negative prompt)**: matte clay, photoreal skin, painterly, hand-drawn, brutalist, gritty texture

## Named references

**Tools / studios**: Spline (spline.design), Womp, Bezi, Polycam

**Brands / sites**: Vercel marketing 2022+, Stripe homepage hero, Linear product marketing, Cron / Notion Calendar launch, Arc browser launch animations, Replit marketing

**Designers**: numerous Spline-community creators; see Dribbble #3d-gradient tag

## When to use

AI-product landing pages, dev-tools marketing, fintech/SaaS heroes, Stripe-era startup hero shots, anywhere wanting "future-y but friendly."

## When NOT to use

brutalism, cottagecore, restrained editorial, anything wanting matte / earthy / hand-made register
