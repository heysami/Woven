# HandyArrows — Single-hand illustration pack (Eren Can Arica)

The entire HandyArrows library — arrows, doodles, full illustrations, infographic accents, underlines — drawn by one hand (Eren Can Arica / Eronred). Single artist, single marker, consistent wobble, one entry to rule them all. Promptable per sub-asset role (arrow / doodle / illustration / infographic / underline).

## Visual signatures

- single artist's hand — Eren Can Arica's recognisable wobbly marker line
- consistent 3-4px marker stroke, slight imperfect wobble
- mono black single-line (occasional limited two-color)
- sub-asset roles cover:
  - **arrows** — 185+ varied (straight, curved, squiggly, looped, double-line, sketchy, chunky); termini: chevron, feathered, splayed
  - **doodles** — playful accents: stars, hearts, sparkles, dots, swirls
  - **full illustrations** — characters and scenes
  - **infographic accents** — circles, brackets, labels, scribble-emphasis
  - **underlines** — handlettered emphasis-strokes under headlines

## Prompt keywords

**Primary**: hand-drawn, marker, single artist, wobbly line, decoration accent

**Material**: vector SVG

**Line**: hand-drawn marker 3-4px, slight wobble

**Color**: mono black on white (occasional 2-color limited palette)

**Style**: arrow / doodle / illustration / infographic-mark / underline (declare sub-role in prompt)

**Avoid (negative prompt)**: 3d, polished icon, photoreal, vector-perfect, antialiased smooth

## Named references

**Illustrators**: Eren Can Arica / Eronred (the singular hand behind the entire HandyArrows pack)

**Movements**: doodle UI accent, editorial spot illustration revival

## Example prompt template

> [Hand-drawn arrow with chevron terminus / playful doodle of sparkle and
> star / full-figure spot illustration of SUBJECT / scribble-emphasis bracket

> white (or limited 2-color), single artist's hand, HandyArrows pack

## When to use

Pointing at headlines, marking flow steps, illustrating "click here", sprinkling accents around copy, editorial spot illos, indie SaaS blog headers, indie product hero, bullet substitutes.

## When NOT to use

dense data UI, brutalism, corporate Fortune-500, minimalist restrained briefs
