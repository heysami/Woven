# Vintage seed-packet lithograph

saturated chromolithograph produce under arched seedsman lettering on buff paper.

**Distinct from** `illust-beatrix-potter-watercolor`: that is soft narrative storybook wash with animal characters; this is commercial chromolithography - dense saturated pigment, idealized prize-winning produce, and label typography doing half the work. **Distinct from** the `aesthetic-cottagecore` aesthetic: that is a whole lifestyle mood; this is specifically the printed seed-packet register with its almanac tables and seedsman caps.

## Visual signatures

- hero produce painted plump and idealized: glossy ribbed tomato, snap peas, carrots, each with leaves and stem attached
- dense chromolitho color: tomato red, pea green, marigold, built in soft stone-grain layers with no visible outlines
- seedsman label typography: arched letterspaced caps for the variety, a swashed script for the cultivar name (Brandywine), small-caps HEIRLOOM ribbons
- almanac print furniture: sowing-calendar tables, hairline-ruled data boxes, tiny typewriter-serif specification text on buff paper

## Prompt keywords

**Primary**: vintage seed packet, chromolithograph, seedsman label, heirloom produce, garden almanac

**Material**: buff paper, letterpress ink, litho stone grain

**Line**: no hard outline, soft litho edges, painted form

**Color**: tomato red, pea green, marigold, leaf sage, seed-packet buff ground

**Style**: idealized plump produce portrait, arched letterspaced caps, swash script variety name, ruled almanac table

**Avoid (negative prompt)**: photoreal photography, flat vector, neon, dark background, cartoon outline

## Named references

**Illustrators**: 19th century seed-house chromolithographers, D.M. Ferry catalog artists

**Products / films**: Burpee seed catalogs, D.M. Ferry & Co. packets, hardware-store seed racks

## Example prompt template

> vintage seed packet chromolithograph of [CONCEPT], plump idealized produce
> painted in dense saturated litho color with soft stone-grain edges, arched
> letterspaced seedsman caps above and swashed script variety name in red,
> small-caps heirloom ribbon, hairline-ruled almanac table below, buff paper
> ground, 19th century garden catalog aesthetic.

## When to use

Garden and grocery brands, farm-to-table packaging, seasonal catalogs, heritage food marketing, planting and recipe apps.

## When NOT to use

dark tech futurism, neon nightlife, sterile clinical UI
