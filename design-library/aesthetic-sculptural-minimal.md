# Sculptural Minimal (aesthetic)

**Tag:** Object-as-typography gallery (AIR's black spiral between letterspaced caps; Apple "AirPods" floating-object spreads; Kinfolk object studies; gallery-plinth web)

**Canonical references:**
- AIR (Awwwards SOTD) - white field, letterspaced "A I R", one black 3D spiral form holding the center.
- Apple AirPods/HomePod spreads - single sculptural object in vast whitespace.
- Donald Judd / Noguchi exhibition graphics; Kinfolk object photography.
- COS / Aesop campaign minimalism with one sculptural prop.

## Cultural identity

A gallery wall as a website: vast white (or bone) field, extremely letterspaced display caps, and ONE abstract sculptural object - a spiral, a stack, a torus, a stone - placed with museum precision where a letter might have been. The object carries all the visual mass; typography frames it like a title card. Distinct from `aesthetic-anti-design` (Rams product-function austerity) and from `aesthetic-swiss-modernist` (typographic grid energy) - here the SCULPTURE is the content, and the page is its plinth.

The defining gesture is **the object in the title**: the form sits between or replaces letterforms ("A [spiral] R"), or holds the exact optical center with type orbiting at the edges.

**Palette anchor:** gallery white `#fafaf8` / bone `#f1efe9`; the object monochrome - ink black `#141414`, graphite `#4a4a4c`, raw clay `#b9a48e`, or chrome; ink `#1a1a1a`, captions `#8c8c86`. ONE material accent allowed in the object itself (brushed steel, walnut), never in the UI.

## Motifs / imagery vocabulary

- ONE sculptural object per viewport: abstract 3D form (spiral, ribbon knot, stacked discs, eroded stone) - matte or single-material, studio-lit, soft contact shadow.
- Extreme letterspacing (0.3-0.8em) on short display words; type at the frame edges, object at center.
- Plinth apparatus: tiny captions ("Fig. 1 - Aluminum, 2026"), index numbers, hairline rules.
- The object may rotate slowly (turntable) or respond to pointer with inertia - one motion, sculptural pace.
- Sections alternate: object spread → text spread → object spread (gallery rhythm).

**Raster/3D required:** the sculptural object (3D render or photo `apple-clean-studio` / illust `3d-arsham-eroded` registers; live three.js for the rotating variant). Type alone without the object is just letterspaced minimalism.

## Voice register

Title-card terse: one to five words per display moment ("AIR", "FORM 03", "WEIGHTLESS"). Body copy reads like exhibition didactics - short, declarative, materials-and-dimensions honest.

## Failure mode

Three objects per viewport (it's a gallery, not a shop); decorative gradients behind the object (the white IS the plinth); letterspacing on body copy (illegible); an object with no shadow/grounding (floating clipart). The tell of the real thing: you could 3D-print the object and put it on a desk.

## Best for

Architecture and industrial-design studios, premium hardware launches, perfume/audio products with iconic silhouettes, art galleries, type foundries, portfolio sites for 3D artists.

## Pairs well with

- **Shells:** `shell-centered-column`, `shell-hero-stack`, `shell-horizontal-scroll-stage` (one object per panel).
- **Styles:** `style-restrained-hairline`, `style-oversized-neo-grotesque` (letterspaced mode), `style-editorial-italic-accent` sparingly.
- **Illust:** `3d-arsham-eroded`, new `sculptural-3d-object`; photo `apple-clean-studio`, `dark-product-stage` (night-gallery variant).
