# Databend / JPEG-corruption glitch

Photo file corrupted at the **bytestream / file-format level** - JPEG block artifacts smeared into impossible geometry, PNG line-corruption causing horizontal channel-shifts, half-loaded image frames with chunks of green/magenta error-color. Distinct from `circuit-bent-glitch` (which is POST-PROCESSED stylised glitch art) - databending is FILE-FORMAT corruption that yields CHAOTIC ACCIDENTAL geometry that no human would design. The randomness is the point.

## Visual signatures

- **JPEG 8×8 macroblock artifacts** smeared across large patches of the image
- entire horizontal scanlines shifted (PNG / BMP corruption signature)
- chunks of pure-green / pure-magenta / pure-cyan "error color" where the decoder gave up
- partially-loaded frames - top portion correct, bottom portion smeared or repeated
- accidental geometry - the corruption finds patterns no human would invent
- often the underlying photo is barely recognisable in places, fully recognisable in others
- color shifts to weird non-photographic hues where blocks misalign

## Prompt keywords

**Primary**: databend, JPEG corruption, file-format glitch, 8×8 macroblock artifact, decoder error, partially-loaded image

**Lighting**: original lighting any - the effect destroys most of it

**Camera / lens**: any source - the corruption is at the file level

**Film stock / post-processing**: heavy JPEG quality drop + bytestream editing in hex editor, OR opening as audio file in Audacity and applying effects, OR sonification of the bytestream - the chaos is accidental, not designed

**Mood**: broken, lost-data, corrupt, error-state, post-internet decay

**Avoid (negative prompt)**: clean glitch, designed pattern, single-technique, calm - databend is CHAOTIC and ACCIDENTAL by definition

## Named references

**Tools / techniques**: hex editor bytestream editing (open JPG as binary, edit middle bytes); audacity-databending (open image as raw audio, apply effects, save back); datamoshing.com toolkit; Mosh-Pro

**Artists**: Rosa Menkman (canonical glitch / databend artist), Phillip Stearns, JODI net-art collective, Nick Briz

**Movements**: glitch art (proper, file-level), post-internet aesthetics, net-art tradition
