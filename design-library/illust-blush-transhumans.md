# Transhumans (Pablo Stanley — punk-zine cyborg ink)

Pablo Stanley's open-source **Transhumans** collection (transhumans.xyz, also on Blush.design) — characters transcending biological limits with cyborg parts, reflective visors, robot heads, mechanical accessories. The actual aesthetic is **punk-zine ink**: bold brush strokes drawn quickly and imperfectly, **stark black and white** base with optional color overlays (the Blush coloring system layers tints on top). Inspired by 80s sci-fi cinema, kawaii minimalism, Japanese illustration, and the literal transhumanism movement. CC0 open-source.

> Correction note: an earlier version of this entry described Transhumans as "glossy 3D plastic sticker." That was a misread. The actual collection is inky, hand-brushed, monochrome-first. This entry now matches the source material at transhumans.xyz.

## Visual signatures

- **bold brush strokes drawn quickly and imperfectly** — not vector-perfect; the imperfection is the signature
- **stark black-and-white base** — characters drawn as B&W ink illustrations
- optional color overlay system (Blush platform feature) — pick a color palette and the tints are layered on top of the B&W base, not painted into it
- cyborg / transhuman themes — characters with robotic arms, visors, antennae, exposed mechanical parts, neon-reflective accessories
- influences: 80s sci-fi films (Blade Runner, Akira), kawaii minimalism, Japanese illustration grammar, punk-zine collage
- isolated characters on transparent or simple flat background (Blush export format)
- often a single character per asset; sometimes character + small mechanical companion

## Prompt keywords

**Primary**: Pablo Stanley Transhumans, punk-zine ink, cyborg character, transhuman, bold imperfect brush

**Material**: brush-ink illustration (NOT vector-flat, NOT glossy plastic), optional color-overlay tint on top of B&W base

**Line**: bold imperfect brush stroke, quick gestural drawing, slight wobble

**Color**: stark black-and-white base (canonical), optional 2-3 color tint overlay (cyan / magenta / neon-green / orange — pick a small palette and overlay it)

**Style**: isolated character, cyborg / robot / visored / antennaed elements, 80s sci-fi inspiration, kawaii proportions

**Avoid (negative prompt)**: glossy plastic, vector flat, smooth gradient, photoreal, painterly soft, machine-perfect lines
