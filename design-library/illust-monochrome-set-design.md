# Monochrome set-design still life

A single-hue 3D prop stage - pink room with pink objects, blue world of blue toys - physical-set-design energy in render form.

## Visual signatures

- Entire scene committed to ONE hue family (pink, blue, sage, butter) across walls, floor, props
- Physical-set logic: plinths, steps, arches, oversized geometric props arranged like a window display
- Soft studio light with gentle contact shadows - the "expensive photo studio" look
- Products or brand objects staged among the props, often slightly oversized
- Matte tactile materials: painted wood, velvet, ceramic, paper

## Prompt keywords

**Primary**: monochrome set design, single color room, prop stage still life, art-directed 3D scene, display-window composition

**Material**: matte painted surfaces, velvet, ceramic, soft studio light

**Line**: no line - soft shading

**Color**: ONE hue family in 4-6 tonal steps, e.g. blush `#f6c9d4` → dusty rose `#c97f95`

**Style**: physical-set-design render, Niika/Pinterest set-stage school

**Avoid (negative prompt)**: multiple hue families, glossy plastic sheen, busy texture, photoreal environment, dark moody light

## Named references

**Illustrators / studios**: Niika (the canonical web case), set-design 3D in the tradition of studio photography sets, Adobe/Figma launch-art monochrome stages

**Movements**: window-display set design translated to 3D render, "Instagram museum" room aesthetics

## Example prompt template

> A monochrome blush-pink set-design still life: a small stepped plinth stage in five tonal pinks holds an oversized ceramic vase, a draped velvet swatch, a potted fern (painted pink), and a floating picture frame. Soft studio key with gentle contact shadows, matte painted-wood and ceramic materials, window-display composition with generous headroom. Art-directed, tactile, expensive-photo-studio render. Single hue family throughout.

## When to use

Agency/portfolio heroes, product-launch stages where the brand owns a color, bento-grid tiles (one mono stage per tile), monochrome-pop briefs needing a softer 3D variant.

## When NOT to use

Documentary/trust registers, technical products needing literal depiction, multi-brand marketplaces.
