# Nature-meets-UI interpenetration

Interface elements physically hosting plant life — topiary growing out of stat cards, vines threading through a dashboard, moss on a button.

## Visual signatures

- REAL UI elements (cards, charts, chips, browser frames) rendered as physical slabs in space
- Botanical growth interpenetrating them: stems emerging FROM a chart's bars, leaves overlapping a card's edge, roots wrapping its underside
- Occlusion is the craft: foliage passes in FRONT of interface layers and casts shadow on them
- Growth maps to meaning: the upward trend sprouts, 100% blooms, the empty state is a seed
- Clean studio or soft garden light; the UI stays crisp where un-grown

## Prompt keywords

**Primary**: plants growing out of UI cards, topiary emerging from dashboard chart, interface slab with vines, organic-tech composite

**Material**: matte UI slabs with subtle thickness, photoreal foliage, soft soil/moss accents

**Line**: none — render realism on both UI and plants

**Color**: neutral UI surfaces (`#f6f6f4` or dark `#16181c`) + true foliage greens, one bloom accent

**Style**: 3D composite where interface and botany share one light

**Avoid (negative prompt)**: leaf emoji decoration, flat vector plants pasted on screenshots, jungle swallowing the UI entirely, drop shadows inconsistent between plant and card

## Named references

**Illustrators**: Crypto-Wealth topiary-from-chips hero (the corpus case), Neuralyn's flower-bedded dashboard, solarpunk product-render school

**Movements**: organic-overgrowth web aesthetics, biophilic product marketing

## Example prompt template

> A 3D composite hero: three floating interface cards — a line chart, a stat chip reading "+34%", a progress ring — rendered as matte off-white slabs with real thickness, suspended over soft shadow. From the line chart's rising curve, a sculpted topiary stem grows upward and bursts into a round leafy crown that overlaps the card above, casting a soft leaf shadow across its surface; fine roots wrap the chart's lower edge into a cushion of moss. Shared studio light, photoreal foliage, crisp untouched UI elsewhere. Growth as the literal metric. Light neutral background.

## When to use

Organic-overgrowth heroes, sustainable-fintech ("watch your wealth grow"), climate dashboards, wellness platforms where progress = growth, feature sections pairing one grown card per capability.

## When NOT to use

Literal product-tour pages (screenshots must stay honest), dark cyber registers, briefs allergic to metaphor.
