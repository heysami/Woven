# Corporate-Memphis Everyday Scenes (Blush)

Flat-vector everyday-life scenes - characters going about daily activity (office, park, walking, shopping, family moments) on a simple single-prop background. Merges Blush's Allura / Big-Shoes / Dayflow / Family-Values / Shopaholics families.

## Visual signatures

- everyday-life scenes (office, park, walking, shopping, parenting)
- clean rounded vector with rounded extremities - sometimes thin 2px optional outline
- muted-to-mid-saturation palette - dusty pink, sage, cream, soft mid-saturation accents
- exaggerated friendly proportions (sometimes big shoes, big hands, simple head shapes)
- scene composition with one prop or simple background
- distinct head-shape variety across characters

## Prompt keywords

**Primary**: flat vector, everyday-life, character, scene composition, friendly proportion

**Material**: flat fill, optional thin 2px outline

**Line**: no line OR thin 2px

**Color**: muted dusty pink + sage + cream + soft mid-saturation accent

**Style**: scene with single prop, friendly storytelling

**Avoid (negative prompt)**: bright saturated, pattern-heavy, realistic anatomy, dark themes

## Named references

**Illustrators**: Vijay Verma (Allura), Elina Cecilia Giglio (Big Shoes), the broader Blush.design corporate-memphis canon

## Example prompt template

> Flat vector everyday-life scene of [SUBJECT doing ACTIVITY], clean rounded
> vector characters with friendly proportions, muted dusty palette of pink
> sage and cream, simple background with one prop, no outline (or optional
> thin 2px), Blush corporate-memphis scene-composition aesthetic.

## When to use

Blog headers, lifestyle/wellness SaaS marketing, parenting content, fashion-adjacent friendly brands, content marketing.

## When NOT to use

brutalism, youth-music, dark themes, serious enterprise B2B
