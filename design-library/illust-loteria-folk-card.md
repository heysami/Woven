# Loteria folk card

flat engraved-line icons in numbered card frames, fiesta color and carnival woodtype.

**Distinct from** `illust-frida-folk-surreal`: that is painterly personal surrealism with symbolic dreamscapes; this is a deck register - each subject is one flat emblematic icon locked in a numbered, named card frame. **Distinct from** `illust-pixar-coco-folk-vibrant`: that is glowing 3D cinematic rendering; this stays hand-printed, flat, and outlined like a cheap chromo deck card.

## Visual signatures

- each subject is a single centered emblem inside a bordered card: number top corner, name banner below (EL GALLO, LA SIRENA, LA LUNA)
- old engraved-line drawing filled with flat chromo color; naive frontal poses, no perspective depth
- fiesta palette on turquoise, rosa fuerte, and sol amarillo grounds with rojo carnaval and tinta negra framing
- carnival print furniture: ornate woodtype slab caps, ticket-scallop borders, papel picado drop ornaments

## Prompt keywords

**Primary**: loteria card, Mexican folk deck, engraved icon, numbered card frame, fiesta

**Material**: cheap card stock, chromo print, letterpress woodtype

**Line**: old engraved outline, naive frontal drawing, flat fill inside line

**Color**: sol amarillo, rosa fuerte, azul turquesa, rojo carnaval, tinta negra

**Style**: single centered emblem per card, number and name banner, ticket-scallop border, papel picado ornament

**Avoid (negative prompt)**: 3D render, gradients, cinematic lighting, painterly, muted palette

## Named references

**Illustrators**: Don Clemente Gallo deck artists, Jose Guadalupe Posada

**Products / films**: Don Clemente Loteria deck, Mexican market chromo posters, papel picado banners
