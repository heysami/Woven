# Hero + feature stack shell

**Tag:** `[marketing · vertical sections · low-density]`

## Structure

Hero + stacked feature sections + CTAs + footer.

- Hero (80-100vh first viewport): headline + sublede + CTA + optional visual
- Feature sections (1-4): alternating left/right text+image
- Social proof / testimonials / pricing (optional)
- Final CTA + footer

## Macro proportions

Hero max-width 1320px centered. Section padding 96-160px top/bottom. Content max-width 1080-1200px.

## Density

Low. Whitespace is the medium.

## Mandatory interactions

Sticky nav on scroll. Smooth scroll to anchors. Hover states on CTAs. Modal for demo. Form submission visual.

## Forbidden

App chrome. Dense data tables.

## Best for

Product launches, SaaS landings, waitlist pages, conference sites.

## Pairs well with

Style: bold-display, aurorism, restrained-hairline. Aesthetic: corporate-memphis for friendly SaaS; cyberpunk for hacker products.
